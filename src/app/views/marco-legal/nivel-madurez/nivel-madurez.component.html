Metodología para Medir el Nivel de Madurez

El sistema incorpora un modelo de evaluación de madurez que permite medir no únicamente si una organización cumple o no con los requisitos de una ley, sino también el grado de avance en la implementación de dichos controles.

Método de Cálculo
  • Artículo cumplido: 100%
  • Artículo parcialmente cumplido: 50%
  • Artículo no cumplido: 0%
  • Artículos no aplicables: Se excluyen del cálculo

El nivel de madurez se calcula como el promedio de todos los artículos aplicables evaluados.
